# Data dictionary

| Field | Meaning |
|---|---|
| application_id | Synthetic identifier; excluded from model |
| cohort | Synthetic application month; excluded from model |
| annual_income | Synthetic annual income (currency units) |
| loan_amount | Synthetic requested principal |
| interest_rate | Synthetic annual rate (%) |
| loan_term_months | Requested term |
| employment_tenure_years | Synthetic tenure; small missing fraction |
| debt_to_income | Synthetic debt-to-income ratio |
| existing_obligations | Synthetic existing obligation amount |
| previous_delinquencies | Simulated count |
| credit_history_years | Simulated history length; small missing fraction |
| loan_purpose | debt_consolidation, home_improvement, medical, education, vehicle |
| employment_category | salaried, self_employed, contract, part_time |
| defaulted | Simulated binary outcome; target only |
